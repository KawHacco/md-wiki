# 編集の仕方

このWikiへの記事追加や編集は、すべてブラウザから行えます。プログラミング知識は不要です。

## 基本的な編集手順

### 1. 編集ボタンをクリック

各ページの下部に「このページを編集する」というボタンがあります。このボタンをクリックしてください。

### 2. GitHub.comにリダイレクト

「このページを編集する」をクリックすると、GitHub.comの編集画面に移動します。

### 3. 内容を編集

ブラウザ上のテキストエディタで、記事の内容を編集します。

### 4. 変更を保存

編集が終わったら、画面下の「**Commit changes**」ボタンをクリックします。

#### 書き込み権限がある場合
- 直接 `main` ブランチに変更が保存されます
- 自動的にビルド・デプロイされます

#### 書き込み権限がない場合
- 自動的にこのリポジトリがあなたのアカウントに **フォーク** されます
- 新しいブランチが作成されます
- **Pull Request** が自動生成されます
- Maintainer がレビュー・マージするまで、変更は反映されません

## 新しい記事を追加する

### 1. 編集したいカテゴリーを選ぶ

例えば、ガイドに新しい記事を追加する場合：

- GitHub上のリポジトリを開く
- `docs/guide/` フォルダを開く

### 2. 新しいファイルを作成

- 「Add file」 → 「Create new file」
- ファイル名を入力（例：`my-article.md`）

### 3. Markdownを記述

以下のテンプレートを使用してください：

```markdown
---
title: 記事のタイトル
description: 記事の説明（オプション）
order: 1
tags:
  - tag1
  - tag2
---

# 記事のタイトル

ここから記事の本文を書きます。

## 見出し2

### 見出し3

**太字**、*イタリック*、`インラインコード` など

```

### 4. Commit & PR

- 「Commit new file」をクリック
- Pull Request を作成
- Maintainer のレビューを待つ

## 画像の追加

### 方法1: GitHub.comの自動アップロード機能（簡単）

1. 記事編集画面で、テキストエリアに画像をドラッグ&ドロップ
2. または、Ctrl+V / Cmd+V で貼り付け
3. 自動的にMarkdownリンクが挿入されます

**例**:
```markdown
![スクリーンショット](https://github.com/user/repo/assets/...)
```

### 方法2: リポジトリに保存

1. GitHub上で `docs/public/` フォルダを開く
2. 「Upload files」をクリック
3. 画像ファイルをアップロード
4. 記事から以下のように参照：

```markdown
![説明](./image.png)
```

## Markdownの書き方

### 見出し

```markdown
# 見出し1
## 見出し2
### 見出し3
```

### テキスト装飾

```markdown
**太字**
*イタリック*
~~打ち消し~~
`インラインコード`
```

### リスト

```markdown
- 箇条書き1
- 箇条書き2
  - ネスト
    - さらにネスト

1. 番号付き1
2. 番号付き2
   1. ネスト
```

### コードブロック

\`\`\`typescript
const greeting = "Hello, World!";
console.log(greeting);
\`\`\`

### リンク

```markdown
[テキスト](https://example.com)
[相対リンク](./other-page.md)
```

### テーブル

```markdown
| 列1 | 列2 |
|-----|-----|
| 値1 | 値2 |
| 値3 | 値4 |
```

### 引用

```markdown
> これは引用です
> 複数行にも対応
```

## よくある質問

### 変更がすぐに反映されません

Pull Request がマージされてから、自動ビルド・デプロイが実行されます。通常 **数分以内** に反映されます。

### Markdownの文法がわかりません

- [Markdown チートシート](https://github.github.com/gfm/) を参照してください
- VitePressは GitHub Flavored Markdown (GFM) に対応しています

### 画像がうまくアップロードできません

- GitHub.comの自動アップロード機能を使っている場合、CDN経由で配信されます
- 自分のリポジトリに保存したい場合は、方法2を使用してください

### 他の記事にリンクしたいのですが？

- **相対パス**: `[ガイド](./guide/getting-started.md)`
- **絶対パス**: `[ガイド](/guide/getting-started)`

どちらでも OK です。`.md` 拡張子は省略できます。
