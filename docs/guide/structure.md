# ページ構成について

## ディレクトリ構成

このWikiはディレクトリ構成によって自動的にカテゴリーが作成されます。

```
docs/
├── guide/          # ガイドカテゴリー
│   ├── getting-started.md
│   └── structure.md
├── faq/            # よくある質問カテゴリー
│   ├── general.md
│   └── technical.md
└── tags/           # タグ一覧ページ
    └── index.md
```

## カテゴリー

`docs/` ディレクトリの直下にあるディレクトリが、各カテゴリーになります：

- **guide** - 使い方ガイド
- **faq** - よくある質問
- **tags** - タグ一覧

### 新しいカテゴリーの追加

新しいカテゴリーを追加したい場合は：

1. `docs/` 直下に新しいディレクトリを作成
2. そこにMarkdownファイルを配置

するだけで、自動的にサイドバーとナビゲーションに反映されます。

## ページの表示順序

サイドバーでのページの表示順序は、フロントマターの `order` フィールドで制御します：

```yaml
---
order: 1
---
```

`order` が小さいほど上に表示されます。`order` を指定しないと、表示順序は未定義です。

## タグ機能

記事にタグを付けることで、タグ別に記事を分類できます：

```yaml
---
tags:
  - tutorial
  - getting-started
---
```

タグは [タグ一覧](/tags/) ページに集約されます。

## 検索機能

サイトの上部にある検索ボックスで、すべての記事を全文検索できます。

- Markdownの本文
- ページのタイトル
- フロントマターの `description`

すべてが検索対象になります。
