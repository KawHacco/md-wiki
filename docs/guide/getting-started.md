# はじめに

このWikiへようこそ！ここではこのWikiの基本的な使い方をご説明します。

## このWikiについて

このWikiは、Markdownを使った簡単なドキュメント管理システムです。GitHub上でMarkdownファイルを編集することで、自動的にこのサイトに反映されます。

## ページの編集方法

各ページの下部に「このページを編集する」というリンクがあります。このリンクをクリックするだけで、GitHubの編集画面に移動でき、ブラウザから直接ページを編集できます。

### 編集手順

1. **「このページを編集する」をクリック**
2. **GitHubアカウントにログイン**（必要な場合）
3. **編集内容を入力**
4. **Commit changes をクリック**
   - リポジトリへの書き込み権限がない場合、自動的にフォークされ、Pull Requestが作成されます
5. **Maintainerによるレビュー・マージを待つ**

## Markdownの基本

Markdownは簡単なテキスト形式です。以下は基本的な書き方です：

```markdown
# 見出し1
## 見出し2
### 見出し3

**太字**
*イタリック*

- リスト1
- リスト2
  - ネストされたリスト

1. 番号付きリスト
2. 二番目

[リンク](https://example.com)

![画像](./image.png)

\`\`\`
コード例
\`\`\`
```

## 記事のフロントマター

各Markdownファイルの先頭には、以下のようなフロントマターを記述します：

```yaml
---
title: ページタイトル
description: ページの説明
order: 1
tags:
  - tag1
  - tag2
---
```

### フロントマター項目

- **title**: ページのタイトル（必須）
- **description**: ページの概要（オプション）
- **order**: サイドバーでの表示順序。数字が小さいほど上に表示されます（オプション、デフォルト: 無限大）
- **tags**: タグのリスト（オプション）
