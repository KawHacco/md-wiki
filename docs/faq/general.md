# よくある質問

## 誰でも記事を編集できますか？

はい、ただし以下の条件があります：

- **GitHubアカウント** が必要です
- **書き込み権限** がある場合は、直接記事を編集できます
- **書き込み権限がない場合** は、自動的にフォークされPull Requestが作成されます

## 変更が反映されるまでどのくらい時間がかかりますか？

Pull Requestがマージされた後、以下の流れで反映されます：

1. GitHubにpushされる
2. CI/CDパイプラインが実行される（自動ビルド）
3. GitHub Pagesにデプロイされる

通常、**数分以内** に反映されます。

## 画像を追加したいのですが？

GitHub.comのファイル編集画面には、**ドラッグ&ドロップやコピペで画像を直接貼り付ける機能** があります。

1. 記事を編集モードにする
2. 画像を編集エリアにドラッグ&ドロップ
3. 自動的にMarkdown形式のリンクが挿入されます

## 古いバージョンの記事に戻せますか？

はい、GitHubの履歴管理機能を使って、以前のバージョンを確認・復元できます。

GitHub上のリポジトリページから「History」タブで過去のコミットを確認できます。

## 複数の画像を使いたい場合、どこに保存すればいいですか？

`docs/public/` ディレクトリに画像を配置し、Markdownから以下のように参照します：

```markdown
![説明](./image.png)
```

または

```markdown
![説明](/md-wiki/image.png)
```

> **注意**: GitHubの自動アップロード機能を使う場合は、画像はGitHubのCDNに一時的にアップロードされ、リポジトリには保存されません。
