# 技術的な質問

## このWikiは何で作られていますか？

このWikiは **VitePress** を使用しています。VitePressはVue.jsとViteをベースとした、高速な静的サイトジェネレータです。

主な特徴：
- Markdownベース
- 静的HTML生成（サーバー不要）
- 組み込み検索機能
- Git統合（最終更新日の自動取得）
- ダークモード対応

## デプロイはどうなっていますか？

**GitHub Pages** を使用して、完全に静的に公開されています。

フロー：
1. `main` ブランチへのpush
2. GitHub Actionsが自動実行
3. VitePressがMarkdownをHTMLに変換
4. 生成されたHTMLが GitHub Pages にデプロイ

サーバーやデータベースはなく、すべて静的ファイルです。

## タグ検索はどのようなしくみですか？

ビルド時に、すべてのMarkdownファイルのフロントマターから `tags` を抽出し、タグごとにページを集計します。

- 完全にクライアントサイド処理
- ビルド時に生成（実行時コストなし）
- [/tags](/tags/) ページで確認可能

## 検索機能はどこに保存されていますか？

検索用のインデックスはビルド時に生成され、ブラウザにダウンロードされます。

- サーバー側の検索APIは不要
- すべてローカルで検索実行
- 高速かつプライベート（検索履歴がサーバーに記録されない）

## GitHubアカウントなしでも見られますか？

はい、このWikiは完全に公開されています。GitHubアカウントがなくても閲覧できます。

ただし、**編集するにはGitHubアカウントが必要** です。

## 最終更新日の表示が空なのはなぜ？

ローカル開発環境では、Git履歴が浅い可能性があります。

```bash
# 完全なGit履歴をダウンロード
git fetch --unshallow
```

または、CI/CDパイプライン上でのビルド結果を確認してください。(^_-)-☆
